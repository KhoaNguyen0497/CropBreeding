# In-game validation checklist

Use a copied save and test together with the actual SVE, Automate and AutoHarvester versions installed on PC/Steam Deck.

Stored readiness mutations (requires live validation): set MutationChance=1 before a plain crop becomes ready. Verify `PendingMutation` appears after overnight growth and all harvested primary items match it. Set chance=0 before another crop becomes ready and verify its no-change marker survives repeated daily updates, config edits and save/reload. At full trait count, maxed or absent selected traits must also record no change with no icon/reroll. Change settings only before the next readiness roll when testing new odds.

Check the static vanilla purple star at different zoom levels/on Steam Deck, coloured crops, trellises, densely planted rows, screen edges and offscreen locations. It must indicate mutation, not item quality, and only appear for ready successful outcomes. Harvest failure/full inventory keeps both outcome and icon. Successful regrow/Rooted harvest removes the icon and old outcome, then the next readiness cycle gets one new result. Seed Saver and sunflower bonus seeds retain original traits; pending state must not leak to harvested items. Giant crop formation/destruction remains vanilla and dead crops show no icon.

Test crop fairy/growCompletely and same-day instant growth, repeated instant growth on a ready plant, overnight mutation before Auto Harvester, vanilla Junimos, hand/scythe and both host/farmhand harvesting. Directly advance phases without calling a growth method: harvest fallback must produce/store the outcome without requiring an icon beforehand. Verify data is synced to clients and saved before next-session Auto Harvester runs. Future in-mod growth effects should call MutationState.EnsurePrepared after advancement. Simulate errors in preparation/read/drawing; log safely without breaking vanilla harvest or unrelated bonuses. The linked production MutationState tests validate lifecycle logic using test doubles, not live event order, rendering, game save serialization or network races.

Error recovery / GMCM (requires in-game validation): inject exceptions inside our prefix/postfix and harvest decoration paths, not vanilla, and check the original action/result/clone survives and the next action still works. Fail each harvest bonus separately; never replay harvests or duplicate awarded items, and verify unrelated bonuses still run. Fail crop mutation after a phase/metadata change and confirm rollback; corrupt GrowthPhaseDeltas and check vanilla phase reset with no repeated bonus accumulation. Fail a menu transaction before/after staging output and ensure inputs/counts are restored, cursor/seeds returned, lock released and the menu can reopen. Test return failure and Lost and Found recovery with full inventory. Fail a Lookup Anything field write and confirm original fields are restored. Test a missing machine texture and patch target. Trigger SMAPI logging and local chat with the option off/on, repeats, unavailable chat, and another player connected (no network messages). Check all 12 GMCM fields, percentage conversion, reset/save, bad JSON/default fallback and out-of-range/non-finite values. Test without GMCM or Lookup Anything. The safety test project uses test doubles to exercise reporting, crop snapshots and GMCM registration callbacks; it does not establish live Harmony/controller/multiplayer compatibility.

Tapper-product traits: test Maple/Resin/Tar Bearing output IDs 724/725/726. Same odds as bar traits: 28 base days gives 25% at level 1, exactly one item at level 4, one plus 25% for a second at level 5. Test initial and regrowing harvests, independent simultaneous material traits, plain quality/no metadata, failed harvests, inventory overflow, hand/scythe/Junimo/Auto Harvester, and no multiplication by High Yield. Only these three tapper products are supported. Test seed merging/removal/stacking for these traits. Live integration requires in-game validation.

Nurse Crop: surround an eligible annual crop with non-fruit trees at stages 0–5, including a diagonal tree, a stump, and a fruit tree. Level 5 must add one or two stages to each living immature non-fruit tree, capped at 4; stage 4/mature trees, stumps and fruit trees stay unchanged. Trees two tiles away stay unchanged. Verify the same bonus applies to all eight neighbors and that multiple crop harvests still cannot push any tree to maturity. Test hand/scythe/Junimo/vanilla-based Auto Harvester, offscreen locations, multiplayer and save/reload. Failed inventory/storage attempts and newly acquired mutations must not advance trees. High Yield and byproducts do not grant extra rolls. Test Rooted together with Nurse Crop, natural regrowers carrying manually injected metadata (no effect or upgrades), winter (can reach stage 4, final step remains natural), SVE annual crops and data-driven wild trees. Verify trait breeding, removal, tooltip and stacking. These integrations require in-game validation.

Rooted: temporarily set RootedChance=1 to force successful restarts. Test parsnip, potato, sunflower, wheat/scythe, colored flowers and SVE single-harvest crops through hand/scythe/Junimo/Auto Harvester. Each harvest must award all primary/bonus/material/Companion/Seed Saver items once, then reset to phase/day zero with original parent traits and flower color. Sunflowers must produce flowers again next cycle, never turn into seed-only crops. Verify current fertilizer/profession/paddy and combined trait timing, unchanged water state except normal paddy watering, repeated cycles without accumulated phase changes, and save/reload. Default levels 1/5 must use 10%/50%; failed harvests, newly mutated Rooted, naturally regrowing crops, pots, excluded crops, dead crops, tools/bombs and chopped giant crops cannot trigger. Season transitions still kill out-of-season plants unless Evergreen 5. A full Auto Harvester must not harvest/restart; successful overflow follows normal drop rules. Lookup Anything should show the restarted initial-growth countdown. This integration still requires in-game validation.

Material traits: verify Copper/Iron/Gold Bearing deliver bars 334/335/336, independently per plant harvest. For 28 base days, levels 1/4/5 yield 0–1 (25%), exactly 1, and 1–2 (25% second). Four base days always gives zero; 5–9 days counts one block. Regrowers use initial base growth on every harvest. Fertilizer, professions, Fast Growth, Researcher, Companion delay and primary multi-yield/High Yield must not affect odds or bar count; High Quality must not upgrade bars. Newly acquired mutations need replanting. Failed/full-inventory attempts give no material drops; Junimo/Auto Harvester route extras through normal storage/overflow. Test SVE base data, stacking, breeding, trait removal and reload. Live harvest integration remains an in-game check.

Controller regression: navigate all inventory rows, slots, mode selector, Remove Trait selector, action and close button with D-pad/stick and activate with A. Rebuild focus/change modes/resize without losing controls. Press and hold B with empty cursor, held item, staged inputs and completed output: close only, no inventory reopening, world action, breeding/removal or duplicated/lost items (full inventory returns overflow as debris). Release B, then a fresh B press should behave normally in the world. Select axe/pickaxe and use it on the station with empty/staged/completed contents: no UI interception; normal removal and intentional content destruction. Check actual PC/Steam Deck bindings; these interaction checks cannot be verified by compilation.

Researcher/Seed Saver: verify inherited Researcher levels 1/5 give 10%/30% default mutation chance and +10%/+50% initial/regrowth time. Combine with Companion and Fast Growth; recalculate twice without accumulating penalties, compare Lookup Anything, and reload saves. Disabling regrowing mutations still wins. Seed Saver rolls once per successful plant harvest and returns at most one exact matching seed with original parent traits/Companion, not mutated output traits. Test coffee, sunflowers, multi-yield crops, a newly acquired Seed Saver mutation (no immediate benefit), full inventory failure, Junimos and Auto Harvester overflow. No High Yield/HQ applies to saved seeds.

High Yield proportional output: at level 5/default setting, one main item becomes two and four coffee beans eight. At level 1, one item gives 1–2 (20% extra) and four give 4–5 (80% extra); five always give six. At level 2, four give 5–6 (60% sixth). Round once across the whole plant harvest, including vanilla bonus produce. Sunflower bonus seeds, wheat hay and Companion output are excluded. Extras share the mutation and sample original quality/color, with independent High Quality rolls. Failed harvest attempts must not release pending extras. Test hand/scythe/Junimo/AutoHarvester, including storage overflow.

Lookup Anything: check trait seeds, their see-also crop links, and actual planted crops. Compare Fast Growth/Companion initial days, with and without Agriculturist (no double reduction). Seed previews assume no fertilizer/paddy adjacency; planted crops include applied bonuses. Compare Fast Growth and Companion interval summaries and next-harvest dates immediately after harvest and on later days, including a countdown longer than the base interval. Evergreen 4 retains ordinary seasons; Evergreen 5 lists all seasons without a false seasonal deadline. Check ordinary crops remain unchanged, pots stay excluded, and opening/reopening lookups never changes a real plant's phases/countdown. Test with Lookup Anything absent too. Display hooks have been compiled, but require an actual in-game integration test.

Evergreen: compare plain seeds and levels 1–4 against level 5 when planting out of season (including winter), using both mouse and controller placement previews. Only level 5 should plant successfully. Test spring/summer/fall/winter transitions and winter-to-spring on watered and unwatered ground, including SVE crops. Regrowers must retain their normal trait-adjusted countdowns and single-harvest plants must still disappear after harvest. Check occupied tiles, trellis collision, forbidden locations and pots remain restricted. A harvested mutation from level 4 to 5 must not protect the original level-4 plant; breed and replant first. Save/reload preserves level-5 protection. Dead plants must not revive. No Auto Harvester-specific patch is used.

1. Temporarily set mutation chance to 1. Grow a plain single-harvest crop with a free trait slot and check one added trait shared by every primary output. Repeat with capped/maxed parents: the full crop-eligible pool still rolls, and blocked selections leave output unchanged without rerolling. X5/Y5/Z4 upgrades only when Z is selected, not on every successful chance roll. Compare hand/scythe/Junimo/AutoHarvester. Check full inventory/chest behavior does not lose or duplicate harvests.
2. Craft a Breeding Machine at Farming 5. Insert five matching trait crops and wrong seeds (reject), then five exact matching seeds (five donors and five seeds consumed; one output). Check plain-seed copying; five X,Y donors + five X1 seeds gives X2,Y; + five Z1 seeds gives X,Y,Z. Reject fewer than five donors or seeds, level-2 seeds, multi-trait seeds and merges over the count/level limits without consuming inputs. Check full inventory collection, saving with pending donor/output, controller use and destroying with contents.
3. With Automate installed, confirm it does not feed or collect from the Breeding Machine. Check trait crops still enter supported ordinary processing machines and that differing trait sets remain separate in storage.
4. Replant in ordinary soil, greenhouse and Ginger Island. Test pots (trait seed refused) and ordinary seeds in pots (normal behavior, no mutation). Compare initial growth with fertilizer, Agriculturalist and rice/taro water adjacency. Fast Growth shortens successful hand/scythe/Junimo/AutoHarvester countdowns once; check full inventory/storage failures and repeated harvest attempts never shorten an existing countdown.
5. Check trait and level differences separate stacks and getOne preserves traits/quality/color. Process and craft trait crops: outputs have no traits and input quality behaves normally.
6. Sunflower: flower may mutate; bonus seeds inherit original traits. Wheat hay has none. Coffee mutated beans can be planted directly. Mixed/forage/fiber/Qi crops never mutate when newly planted. Run catalog and inspect all installed SVE mappings, including Ancient Fiber.
7. Grow a giant crop using differently traited plants. Formation remains vanilla; axe drops have no traits.
8. Test cleanup on a backup with crops, placed machines, chest/inventory machines and pending contents; save/reload without the mod and check for missing-item remnants.
9. Test multiplayer clients planting, harvesting, collecting and reconnecting. Trait modData should sync; everyone must have the mod.

Known unresolved design decisions are recorded in README (16). Regrowing mutations now default to enabled; verify each successful harvest can mutate produce while the standing plant retains its inherited traits. Explicitly disabling the config must still suppress regrowing mutations. Auto Harvester compatibility relies only on its vanilla `Crop.harvest` call; there is no reflection integration or optional dependency. Use its updated vanilla-harvesting version.

10. Check explicit `trait:level` metadata, including level 1. Harvest max-count plants with level-1 traits: upgrades remain possible without adding types. Harvest plants with all traits at level 5: no trait loss. Check level-scaled initial growth, regrowth and yield at levels 1 and 5.

11. With new mutations disabled, repeatedly harvest a regrowing trait plant: every primary output keeps the same traits and levels and remains a valid breeding donor. Confirm removed Premium/Hardy metadata has no gameplay effect or tooltip entry.

12. Open an empty machine with mouse and controller. Put five identical donors in the left slot and seeds in the right, select Breed, then collect from the left. Test invalid seeds, 4/5/10 seed stacks and 4/5/10 donor stacks; verify exactly five of each consumed and surplus retained. Mixed trait/level/quality/Companion stacks must not combine. Check seed removal/swapping, tooltips, UI resizing and controller navigation between slots/button/inventory. Close with seeds/cursor items and a full inventory: unused items return or drop safely, pending donor/output persists. Test normal close and emergency close.
13. Open the same machine from two multiplayer clients: only one should acquire the menu lock. Test disconnecting while open, destroying the machine while open, and opening another machine at the same tile later.
14. Fast Growth can mutate on all eligible crops; it shortens regrowth only where the crop already regrows.

15. High Quality: test levels 0/1/5 with normal/silver/gold/iridium baseline produce. Upgrade only one tier, gold goes directly to iridium, iridium never changes. Multi-yield crops and High Yield bonus items roll individually and split by quality. Check hand/scythe/Junimo/AutoHarvester, colored flowers, full inventory/hut/chest and repeated failed attempts (no duplicate bonus drops). Fertilizer/farming quality still forms the baseline. A newly mutated High Quality trait has no current-harvest effect; inherited levels apply on every harvest. Sunflower bonus seeds and wheat hay stay unchanged.

16. Companion mode: seed without Companion rejects; assigned/unassigned Companion at levels 1–5 accepts eligible chosen crops; preserve other seed traits. Consume exactly one seed and one crop. Same selection rejects without consumption, different selection replaces, own-crop selection works. No crop traits/quality copy. Close/reopen pending and completed selections, test controller mode button and locked mode switching.
17. Breed Companion donor/seed choices: donor wins when assigned, seed wins when donor unassigned, both unassigned stays empty. Check plain-seed copying, multi-trait/level restrictions, level-5/count-cap rejection, selection-aware stacking, save/reload, planting, primary output and sunflower bonus seed inheritance, processing strips both metadata fields, cleanup.
18. Initial growth 5 + companion base 7 must total 9. Regrowth 4 + companion base 7 must total 8; with Fast Growth 5 it must total 6. Reapply fertilizer/speed recalculation twice without accumulating penalties. Test SVE mapping, invalidated crop data and cleanup restoring timing. Companion output rolls once per successful harvest, exactly one normal-quality trait-free item, also when same item as main crop. Test High Yield + High Quality, failed/full inventory, Junimos and Auto Harvester storage/overflow; no bonus on failure, no recursion.

19. Interact with the station while holding a donor, seeds, ordinary item, or empty hands: open the UI without consuming/depositing the held inventory item. Breed only through the two UI slots/button. Confirm item-input probes reject direct deposits and axe/pickaxe actions still remove the station.

Remove Trait mode: test mouse/controller cycling through all three modes and traits, resize, reopening staged/completed seeds, and rejecting mode changes with occupied slots/cursor. Insert from a seed stack and verify only one is taken. Ordinary donor crops and traitless seeds must reject; coffee seeds may accept. Remove one selected trait without changing other levels/quality/Companion choice; removing Companion clears its choice; removing last trait produces plain seed. Repeated Remove on completed output must do nothing. Check breaking the station loses contents and multiplayer mutex still blocks concurrent edits. UI requires in-game validation.
